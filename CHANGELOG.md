# Changelog

All notable changes are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Public contribution, issue and pull request workflows.
- Automated Python and JavaScript checks.
- Docker and Docker Compose development configuration.

## [0.1.0] - 2026-07-28

### Added

- Multilingual employee chat with browser speech-to-text.
- Department-aware hybrid retrieval with citations.
- Visible multi-model orchestration and answer verification.
- Conversation history, feedback and quality reporting.
- Confirmation-gated simulated actions and audit records.
- Project-local Linux service lifecycle controls.

### Security

- Runtime data, credentials, uploads, logs and model files are excluded from version control.
- Department access is applied before retrieval.
